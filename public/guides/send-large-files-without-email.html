The Problem: The Persistent 25 MB Email Attachment Barrier

Despite fiber-optic internet connections and terabyte hard drives, email protocols remain bound to architecture established in the early 1990s. Popular email providers—including Gmail, Microsoft Outlook, Yahoo Mail, and Apple iCloud Mail—impose strict attachment size limits ranging between 20 MB and 25 MB.

When you attempt to email a high-resolution PDF portfolio, a ZIP archive containing software code, or a raw video recording, your email client either throws a bounce error or forces you to upload the file to a cloud drive (Google Drive, OneDrive) that creates unwanted shared folder permissions and clutters your personal storage quota.

Why Traditional Email Attachments Are Inefficient

Email was designed for ASCII text messages. To send binary files (like images or ZIPs), email clients must encode the data using Base64. Base64 encoding increases the raw file size by approximately 33%. Consequently, an 18 MB video file expands into roughly 24 MB of text overhead, easily triggering provider size rejections.

Technical Deep Dive: How Chunked Multipart Streaming Enables 2GB Uploads

Cloudflare Workers enforce a default request body payload limit of 100 MB. To support 2 GB file transfers smoothly across consumer web connections, DropItOver implements a client-side chunked multipart streaming engine:

  1. Client-Side Slicing: The browser's File API slices large files into distinct 8 MB binary segments.
  2. Chunk Encryption: Each 8 MB segment is encrypted with authenticated AES-256-GCM using unique IVs.
  3. Multipart R2 Ingestion: Chunks are uploaded sequentially to Cloudflare R2 object storage using multipart upload APIs with retry logic.
  4. Atomic Assembly: Once all chunks are verified via cryptographic checksums, the multipart upload is finalized atomically into a single downloadable entity.

Bandwidth Optimization & Compression Guidelines

To ensure lightning-fast upload and download speeds when sending massive files:

  • Pre-Compress Directory Trees: When sending folders containing thousands of small files (like source code or icon sets), zip them first to eliminate HTTP per-file overhead.
  • Use Modern Video Codecs: When exporting video drafts, HEVC (H.265) or AV1 achieves 50% smaller file sizes than legacy H.264 at identical visual quality.
  • Direct P2P Alternative for Local Transfers: If your recipient is in the same room, use DropItOver's direct Wi-Fi mode to transfer at 100+ MB/s without uploading to cloud storage at all.

Yes. The recipient simply opens the link in their web browser (Chrome, Safari, Edge, Firefox) on any phone, tablet, or PC and clicks 'Download'. No app or account is required.

What is the total size limit per share link?
You can upload up to 2 GB per individual file, and bundle multiple files up to a combined total of 8 GB per share link.
Is my upload paused if my internet connection drops briefly?
