Our Origin Story: Breaking Down Ecosystem Walls

For over a decade, major hardware and operating system corporations have built artificial walled gardens. Apple's AirDrop provides a fluid file sharing experience—but only if every person in the room owns an iPhone, iPad, or Mac. Google's Quick Share prioritizes Android and Windows, yet leaves iOS and macOS in isolation. When an iPhone user needs to send a 2 GB 4K video recording to a Windows 11 PC, or when a Linux developer needs to send a code repository to an Android phone, they are forced to deal with slow USB cables, bloated desktop drivers, or cloud drive accounts burdened with storage paywalls and privacy risks.

DropItOver was built in 2026 to eliminate these artificial barriers permanently. By leveraging open web standards—specifically WebRTC DataChannels, the W3C Web Cryptography API, and distributed edge computing—DropItOver delivers a uniform, high-speed file transfer experience across every browser, operating system, and hardware architecture without software downloads or account sign-ups.

Technical Architecture: How DropItOver Works

DropItOver provides three specialized modes of operation, engineered for distinct networking conditions and collaborative workflows:

1. Direct Wi-Fi P2P Transfer (Zero-Server Architecture)

When devices share the same local Wi-Fi or local area network (LAN), DropItOver coordinates a direct peer-to-peer connection via WebSockets signaling on Cloudflare Workers and Durable Objects.

Device A (Sender) Browser WebRTC Engine
↔
Signaling Broker Cloudflare Durable Object (Hashed IP)
↔
Device B (Receiver) Browser WebRTC Engine

Once SDP offers/answers and ICE candidate handshakes complete, a direct SCTP-over-DTLS data channel is established. Your file data moves directly across local router antennas at speeds up to 100+ MB/s without touching our servers or any cloud database.

2. Ephemeral Encrypted Link Sharing

When recipients are remote or on different networks (e.g., cellular 5G data), DropItOver provides high-speed link shares up to 2 GB per file (8 GB total per link bundle):

  • Chunked Encryption: Files are split into 8 MB binary chunks and encrypted client-side/edge using authenticated AES-256-GCM.
  • Zero Persistent Footprint: Files are held in temporary ephemeral object storage with strict TTL lifespans (1 hour to 7 days).
  • Self-Destruct Option: "Burn after download" automatically shreds and purges data the exact millisecond the recipient finishes downloading.

3. Real-Time Collaborative Transfer Rooms

For classrooms, team scrums, and multi-person workshops, DropItOver Rooms allow up to 8 devices to join a temporary mesh network using a short 8-character join code or QR scan. Participants can swap files and live text snippets bidirectionally with zero configuration.

Our Core Security & Privacy Principles

  1. No Account, No Fingerprinting: You are never asked for an email address, phone number, password, or credit card. We generate random ephemeral session tokens that exist solely in browser memory.
  2. Cryptographic Authenticity: All browser-to-browser WebRTC streams use DTLS encryption (ECDSA / AES-128-GCM) with perfect forward secrecy.
  3. Strict Data Minimization: What is not stored cannot be leaked, hacked, or subpoenaed. Direct transfers bypass servers entirely, and link shares are systematically wiped via automated cron sweepers every 10 minutes.
  4. Accessible to Everyone: Fast, clean, free, and lightweight. We prioritize minimal bundle size (< 50 KB initial payload) so DropItOver loads instantaneously on 3G, 4G, and satellite internet connections globally.
